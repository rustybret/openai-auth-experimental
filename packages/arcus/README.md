# Arcus Consumer Template (`packages/arcus`)

This directory provides the canonical entry point for projects distributing software via the Arcus gateway.

## Structure

- `arcus.json`: Project manifest defining the package ID, software type, and distribution channel. (Copy from `arcus.json.example`).
- `opencode-openai-auth.json`: Component manifest for OpenCode plugin (`opencode-openai-auth`).
- `pi-openai-auth.json`: Component manifest for Pi extension (`pi-openai-auth`).
- `bootstrap.sh`: Automated toolchain setup script.
- `toolchain/`: Symlink to the Arcus-managed `arcus-publisher` installation (generated by `bootstrap.sh`, gitignored).
- `.gitignore`: Ignores `toolchain/`.

## Setup

Run the bootstrap script from the repository root:

```sh
sh packages/arcus/bootstrap.sh
```

This will:
1. Verify `arcus` CLI is installed and available on `PATH`.
2. Install or update the `arcus-publisher` package (`arcus install arcus-publisher`).
3. Symlink `packages/arcus/toolchain` to the Arcus installation directory.
4. Symlink `.opencode/skills/arcus-publisher` to `packages/arcus/toolchain/skill`.
5. Run `arcus manifest verify-toolchain` to validate the toolchain headers.

## Packaging & Publishing

The repository follows the canonical Arcus distribution contract:
Release artifacts reside under `dist/<version>/<sequence>/<package>/`.

### 1. Package Suite
```sh
bun run pack:arcus      # packages all components to dist/<version>/<sequence>/
bun run pack:opencode   # packages opencode-openai-auth
bun run pack:pi         # packages pi-openai-auth
```

### 2. Publish Suite
```sh
bun run publish:arcus   # uploads to GitHub Releases and stages to Arcus manifests
```

### 3. Gateway Submission Commands
- **Submit Release Bundle**:
  ```sh
  arcus publish submit [bundle_dir] --gateway https://arcus-auth.rustybret.com
  ```
- **Query Submission Diagnostics & Status**:
  ```sh
  arcus publish status <submission_id> --gateway https://arcus-auth.rustybret.com
  ```

## Submodule Prohibition

Projects distributing via Arcus must **NOT** add the `arcus` repository as a git submodule. Direct writes to the Arcus repository from consuming projects are strictly prohibited. All updates to the publisher tooling are managed through `arcus install arcus-publisher`.
